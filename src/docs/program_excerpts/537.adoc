== دیگران آیینه ما هستند

.مولوی، دیوان شمس، غزل شماره ۳۰۶۰
[.poem]
....
کی دید خربزه زاری لطیف بی سرخر
که من بجستم عمری ندیده ام باری
....

.مولوی، مثنوی، دفتر اول، بیت ۱۳۲۹
[.poem]
....
پیش چشمت داشتی شیشهٔ کبود
ز آن سبب، عالَم کبودت می‌نمود
....
